# Ravel Institute of Nursing

Modern redesign of [ravelinstitute.com](https://ravelinstitute.com/), inspired by the institutional blue-and-gold look of [wbuhs.ac.in](https://wbuhs.ac.in/).

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content & assets

- Site copy and links: `src/data/site.ts`, `src/data/blogs.ts`
- Images: `public/images/`
- PDFs (prospectus, fees, affiliations): `public/docs/`

## Portals (UI placeholders)

- `/login/admin` — Admin Login
- `/login/user` — User Login
- `/login/student` — Student Login
- `/payment` — Payment gateway placeholder
